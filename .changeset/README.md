# Changesets in Agent Mesh

This directory contains changeset records for published `@tupynambalucas-dev/mcp-*` and `@tupynambalucas-dev/plugin-*` packages.

## Creating a Changeset

Run:

```bash
pnpm changeset
```

Select the packages modified, select the semver bump level (`patch`, `minor`, `major`), and provide a Conventional Commit description in en-US.
