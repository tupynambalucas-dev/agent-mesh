## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Repository Governance Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `readme-architect`, `monorepo-architect`, `community-health-architect`, `license-architect`, `github-standards-architect`.
- **Key Capabilities**:
  - Organization-wide .github directory taxonomy
  - Mandatory CODEOWNERS enforcement
  - Composite actions standard
  - Zero-script monorepo releases
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
