All notable changes to `@tupynambalucas-dev/plugin-appsheet` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: AppSheet Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `appsheet-prompt-architect`, `appsheet-data-operator`, `appsheet-ui-architect`.
- **Key Capabilities**:
  - Sovereign launcher routing to @tupynambalucas-dev/mcp-appsheet
  - Headless Playwright isolation hook
  - Diataxis reference guides
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
