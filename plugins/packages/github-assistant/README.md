# GitHub Assistant Domain Plugin (`@tupynambalucas-dev/agent-plugin-github-assistant`)

The authoritative Antigravity developer assistant plugin for Git branching, Conventional Commits v1.0.0, SSH commit signing, Pull Request lifecycle, and Actions CI/CD workflow management.

## Modular Skills Catalog

1. **`github-flow-coach`**: Guides and assists developers with standard Git branching, Conventional Commits formatting, SSH commit signing, Pull Request creation, and GitHub CLI operations.
2. **`github-actions-manager`**: Monitors, diagnoses, and manages GitHub Actions continuous integration and deployment workflows.

## Connection Mode

- Mode A: Cluster Envoy AgentGateway (`http://localhost:8080/mcp`)
- Mode B: Automatic fallback via `pnpm dlx @tupynambalucas-dev/agent-mcp-github`
