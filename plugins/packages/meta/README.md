# Meta Architecture Domain Plugin (`@tupynambalucas-dev/agent-plugin-meta`)

Enterprise Antigravity plugin for agent mesh meta-architecture: context routers, markdown governance, skill architecture, and plugin manifests.

---

## Modular Skills Catalog

1. **`agent-router-architect`**: Authors and audits hierarchical `AGENTS.md` context routers, enforcing parent-child XML context inheritance and bounded context rules across monorepos.
2. **`markdown-architect`**: Authors and validates GitHub Flavored Markdown (GFM) documents enforcing strict zero-emoji standards, table alignment, and GFM alert callouts.
3. **`skill-architect`**: Designs, refines, and validates Antigravity Agent Skills (`SKILL.md`), authoring frontmatter schemas, single-responsibility instructions, and evaluation test cases.
4. **`plugin-manifest-architect`**: Authors and validates Antigravity plugin manifests (`plugin.json`), pnpm workspace configuration, and MCP server configuration bindings.

---

## Standards Enforced

- **Hierarchical XML Context**: `<context-hierarchy>` tag specification at the root of every bounded context router.
- **Enterprise Governance**: SSH commit signatures, Conventional Commits v1.0.0, Zero-Emoji invariant.
