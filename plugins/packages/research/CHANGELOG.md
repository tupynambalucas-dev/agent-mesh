## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Research Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `documentation-researcher`, `web-deep-researcher`.
- **Key Capabilities**:
  - Sovereign launcher routing to @tupynambalucas-dev/mcp-firecrawl
  - Context7 live documentation research
  - Token-conservation web extraction
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
