All notable changes to `@tupynambalucas-dev/plugin-secrets` will be documented in this file.

## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Secrets Management Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `infisical-vault-operator`, `secret-rotation-operator`.
- **Key Capabilities**:
  - Sovereign launcher routing to @tupynambalucas-dev/mcp-infisical
  - Zero-plaintext secret leakage invariant
  - Kubernetes InfisicalSecret synchronization
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
