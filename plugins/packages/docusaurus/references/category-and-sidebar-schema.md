# Docusaurus Category and Sidebar Schema Reference

## 1. `_category_.json` Schema

Each folder in `docs/` may include a `_category_.json` to configure sidebar rendering:

```json
{
  "label": "Core Infrastructure",
  "position": 1,
  "collapsible": true,
  "collapsed": false,
  "className": "sidebar-category-core",
  "link": {
    "type": "generated-index",
    "title": "Core Infrastructure Overview",
    "description": "Guides and references for core cluster infrastructure and gateways.",
    "slug": "/category/core-infrastructure"
  },
  "customProps": {
    "badge": "Active"
  }
}
```

### Parameter Reference
- **`label`** (string, required): Display name in the sidebar.
- **`position`** (number, optional): Sort order relative to peers (supports floats like `1.5`).
- **`collapsible`** (boolean, optional): Whether users can expand/collapse (default: `true`).
- **`collapsed`** (boolean, optional): Initial state (default: `true`).
- **`link.type`** (string): `generated-index` creates an automatic landing page listing child documents; `doc` points to an explicit MDX document ID.

---

## 2. Autogenerated vs Manual Sidebar

Prefer autogenerated sidebars in `sidebars.js` to eliminate manual route registration:

```javascript
export default {
  docsSidebar: [{ type: 'autogenerated', dirName: '.' }],
};
```
