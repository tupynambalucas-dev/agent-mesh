## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Docusaurus Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `docusaurus-architect`, `docusaurus-mdx-architect`, `docusaurus-auditor`.
- **Key Capabilities**:
  - Diataxis documentation quadrant structuring
  - MDX v3 compliance checking
  - Crowdin localization isolation
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
