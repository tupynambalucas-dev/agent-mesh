# Google Workspace Domain Plugin (`@tupynambalucas-dev/plugin-gwork`)

Enterprise Antigravity and Claude Code plugin for Google Workspace automation: Drive lifecycle management, 1NF normalized Sheets workbooks for AppSheet backends, and richly formatted Docs publishing.

---

## 1. Overview

`@tupynambalucas-dev/plugin-gwork` provides specialized skills to manipulate Google Drive folders, synthesize 1NF relational workbooks, and publish clean documentation.

---

## 2. Modular Skills Catalog

| Skill | Primary Focus | Tools & Targets |
| :--- | :--- | :--- |
| **`gwork-drive-operator`** | Drive searching, folder organization, metadata updates, access sharing. | Google Drive API v3. |
| **`gwork-sheets-architect`** | 1NF normalized workbook synthesis, AppSheet backends, frozen headers. | Google Sheets API v4. |
| **`gwork-docs-architect`** | Typographic hierarchy, enterprise specs, document styling. | Google Docs API v1. |
