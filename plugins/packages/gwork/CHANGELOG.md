## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Google Workspace Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `gwork-drive-operator`, `gwork-sheets-architect`, `gwork-docs-architect`.
- **Key Capabilities**:
  - Sovereign launcher routing to @tupynambalucas-dev/mcp-gwork
  - Normalized 1NF Google Sheets synthesis
  - Google Drive governance
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
