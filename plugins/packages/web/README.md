# Web Domain Plugin (`@tupynambalucas-dev/plugin-web`)

Enterprise Antigravity and Claude Code plugin for web browsing, headless Playwright testing, developer desktop browser pairing, and structured extraction.

---

## 1. Overview

`@tupynambalucas-dev/plugin-web` provides browser automation, non-intrusive desktop pairing, and clean content extraction.

---

## 2. Modular Skills Catalog

| Skill | Primary Focus | Tools & Targets |
| :--- | :--- | :--- |
| **`browser-operator`** | Headless browser workflows, form filling, snapshot navigation, dialog handling. | `playwright` MCP server. |
| **`browser-auditor`** | Live desktop browser pairing via CDP or Extension bridge without restarting processes. | `playwright` MCP server. |
| **`web-extractor`** | Markdown extraction, site mapping, and token-optimized scraping. | `firecrawl` MCP server. |
